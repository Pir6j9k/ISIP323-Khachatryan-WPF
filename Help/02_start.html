Начало работы

Для запуска программы дважды щёлкните по ярлыку КосметическаяЛажа.exe или запустите приложение через Visual Studio (клавиша F5).

Системные требования

  • Операционная система: Windows 10 / 11 (64-разрядная)
  • .NET Framework 4.7.2 и выше
  • Microsoft SQL Server (LocalDB или Express)
  • Оперативная память: не менее 2 ГБ
  • Разрешение экрана: не менее 1024?768

Интерфейс

Главное окно состоит из двух частей:

  • Левая панель — навигация по разделам и информация о пользователе.
  • Рабочая область (справа) — содержимое выбранного раздела.
